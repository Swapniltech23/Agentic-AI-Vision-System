# Agentic AI Vision System

## Description
A multimodal AI vision system for navigation assistance and security monitoring using YOLOv8, OpenCV, Streamlit and Text-to-Speech.

## Features
- Real-time object detection
- Navigation assistance
- Security monitoring
- Voice alerts
- Streamlit interface

## Technologies
- Python
- YOLOv8
- OpenCV
- Streamlit
- PyTorch
